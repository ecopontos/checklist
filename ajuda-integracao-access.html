🔄 Alterações de roteiros no Access

Procedimento para editar um ponto no aplicativo e devolver a alteração com segurança ao banco compartilhado do Access.

Como a integração funciona

A alteração é salva primeiro neste computador. Depois, o aplicativo a entrega ao GAS, onde ela aguarda a importação pelo operador do Access.

1. AplicativoSalva e envia a alteração
2. GASMantém a fila pendente
3. AccessValida, aplica e confirma

O que pode ser alterado

  • Roteiro do ponto;
  • Ordem dentro do roteiro;
  • Status ativo ou inativo.

Somente pontos existentes com um ID Rota numérico vindo do Access são devolvidos. Nome, endereço e pontos novos permanecem apenas no aplicativo nesta primeira versão.

Configuração inicial

  1. Abra Admin → Sincronização Google.
  2. Confira a URL do Web App do Google Apps Script.
  3. Informe o token fornecido pelo administrador no campo Token para alterações de roteiros.
  4. Clique em Verificar agora.
  5. Confirme que aparece API GAS v3: compatível e que a integração de roteiros não mostra erro.

O token é confidencial. Não envie por mensagem, não coloque em planilhas e não o grave junto ao código do aplicativo.

Editar e enviar pelo aplicativo

  1. Abra Roteiros e localize o ponto pelo cliente ou pelo ID Rota.
  2. Clique em Editar.
  3. Altere o roteiro, a ordem ou o status e clique em Salvar.
  4. O aplicativo tenta enviar imediatamente. Se a internet estiver indisponível, a alteração fica segura na fila local.
  5. Em Admin, use Verificar agora para tentar novamente.

Entender os indicadores

  • Alterações de Roteiro Pendentes: 0 significa que todas chegaram ao GAS. Ainda podem estar aguardando o Access.
  • PENDENTE na aba AlteracoesRoteiros significa que o GAS recebeu, mas o Access ainda não confirmou.
  • PROCESSADO significa que o Access aplicou e confirmou a alteração.

Importar no Access 365

  1. Abra o frontend integrado do ColetaFlex.
  2. No formulário de roteiros, clique em Importar alterações do app.
  3. Na primeira utilização, informe o mesmo token configurado no GAS.
  4. Confira a prévia com ID, roteiro, ordem e status.
  5. Clique em Sim somente se todas as linhas estiverem corretas.
  6. Aguarde a mensagem informando que as alterações foram aplicadas, confirmadas no GAS e exportadas.

Antes de gravar, o Access verifica se todos os IDs e roteiros existem. O lote inteiro é aplicado em uma transação: se uma linha for inválida, nenhuma alteração é gravada.

Quando ocorrer uma falha

  • Alteração salva, mas não enviada: confira URL, token e internet na tela Admin; depois clique em Verificar agora.
  • Token recusado no Access: aceite apagar o token salvo e informe o token atual na próxima tentativa.
  • Validação recusada pelo Access: nada foi aplicado. Corrija o ID ou o nome do roteiro antes de tentar novamente.
  • Access aplicou, mas não confirmou no GAS: execute a importação novamente. Reaplicar os mesmos valores é seguro.

Cuidados importantes

  • Não edite manualmente a aba AlteracoesRoteiros.
  • Não compartilhe o token da integração.
  • Confira sempre a prévia antes de confirmar no Access.
  • Para um primeiro teste, abra um ponto existente e salve sem mudar os valores. Assim todo o percurso é validado sem alterar o cadastro.
